# 🎮 Unity: Do Zero ao Avançado

Um livro completo de Unity em português, com 130+ capítulos práticos — do primeiro `Debug.Log` até shaders, multiplayer, DOTS e shipping.

🌐 **Online:** https://wallysondevs.github.io/unity-book/

## Trilhas

1. Boas-vindas e Fundamentos
2. Instalação e Primeiros Passos
3. C# para Unity
4. GameObjects e Componentes
5. Scripting Básico
6. Input e Controles
7. Física 3D
8. Física 2D
9. Animação e Mecanim
10. Gráficos, Materiais e Iluminação
11. UI e UX no Unity
12. Áudio e Som
13. Persistência e Save Games
14. Multiplayer e Rede
15. Performance e Otimização
16. Editor e Ferramentas
17. IA e Gameplay
18. Deploy e Projetos Práticos

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Wouter (hash routing — funciona no GitHub Pages)
- Framer Motion + Lucide Icons

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

## Deploy (GitHub Pages)

```bash
npm run build
npm run deploy   # publica dist/ na branch gh-pages
```
